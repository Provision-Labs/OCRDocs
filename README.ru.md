## Установка и запуск

### Windows

### `Установка`

1. Скачайте [установочный файл](https://provlabs.tech/downloads/provision_ocr_setup.exe)
2. Запустите `provision_ocr_trial.exe`
3. В открывшемся окне выберите язык, путь для установки программы
4. Нажмите `Установить`

### `Запуск`

1. В открывшемся консольном окне дождитесь статуса `Provision Scan: READY`
2. В поле `Listening on` будет указан URL для API
3. Из папки, в которой установлен OCR запустите файл `ProvisionOCR.exe`

### Linux

`В разработке`

### Docker

1. Скачайте docker образ:

```bash
docker pull registry.provlabs.tech/hub/provision_ocr:latest
```

2. Запустите контейнер:

**CMD / bash:**

```bash
docker run -d --name provision_ocr --gpus all -p 8098:8098 --restart always registry.provlabs.tech/hub/provision_ocr:latest
```

**PowerShell:**

```powershell
docker run -d `
  --name provision_ocr `
  --gpus all `
  -p 8098:8098 `
  --restart always `
  registry.provlabs.tech/hub/provision_ocr:latest
```

> `--gpus all` тег для запуска на GPU. Для запуска на CPU или MacOS нужно исключить данный тег

3. Проверьте, что контейнер запущен:

```bash
docker ps
```

После успешного старта сервис доступен по адресам:

- API:          `http://localhost:8098/`
- Swagger UI:   `http://localhost:8098/docs`
- Health check: `http://localhost:8098/health`

4. Остановка контейнера:

```bash
docker stop provision_ocr
```

## Эндпоинты API

### Health

```
POST /health
```

Проверка доступности сервиса (liveness probe). Возвращает `503`, если service middleware отключён.

**Ответы:**

| Код   | Описание                                         |
|-------|--------------------------------------------------|
| `200` | Сервис работает нормально                        |
| `503` | Сервис временно недоступен (middleware отключён) |

**Пример ответа (200):**

```json
{
  "status": "ok",
  "version": "0.9.3"
}
```

`version` — версия продукта собранного билда (берётся из файла `VERSION` на этапе компиляции), не зависит от версии
самого контракта API. Значение `"unknown"` возможно, только если билд собран без определения версии.

### Перезагрузка моделей

```
POST /reload_service
```

Перечитывает `provision_ocr.ini` (переопределения путей моделей в секции `[weights]` и ширины входа `text_*_img_w`) и
per-template JSON-конфиги, после чего выгружает все загруженные **TorchScript**-сессии: Mask R-CNN, CRAFT,
TextRecognizer, CharRecognizer, EfficientNet, Edge. Сессии лениво пересоздаются при следующем запросе — это позволяет
подменить веса на диске без перезапуска процесса.

Ini-файл целиком парсится и валидируется **до** применения изменений: если какое-то значение не парсится, запрос
завершится с `400`, где `message` укажет ключ, значение и файл:строку, а текущая конфигурация останется без изменений.

Перезагрузка дожидается завершения выполняющихся в данный момент задач распознавания, поэтому ответ может занять
несколько секунд. Одновременно может выполняться только одна перезагрузка — повторный вызов во время выполнения получит
`409`.

Эндпоинт ограничен admin allowlist (`reload_allow`) — вызовы не из разрешённого списка IP получают `403`.

**Ответы:**

| Код   | Описание                                                                                       |
|-------|------------------------------------------------------------------------------------------------|
| `200` | Перезагрузка выполнена — сессии выгружены, модели будут пересозданы при следующем запросе      |
| `400` | `provision_ocr.ini` не прошёл валидацию — `message` содержит ключ, значение и файл:строку      |
| `403` | IP вызывающего не входит в список `reload_allow`                                               |
| `409` | Перезагрузка уже выполняется — повторите запрос позже                                          |
| `500` | Ошибка перезагрузки после валидации (недоступна директория весов, не удалось выгрузить сессии) |

**Пример ответа (200):**

```json
{
  "status": "ok",
  "config_reloaded": true
}
```

`config_reloaded` равно `false`, если процесс был запущен без директории конфигурации (тесты / embedders).

### Статус лицензии

```
GET /license/status
```

Только для чтения снимок состояния подсистемы лицензирования. Эндпоинт исключён из проверки лицензии (license gate),
поэтому дашборды могут опрашивать его даже при сломанной или истёкшей лицензии. Он **не** содержит данных,
идентифицирующих машину, или ключевого материала для подписи. Конкретные причины отказа (несовпадение fingerprint,
исчерпан лимит запросов, подделан счётчик и т.д.) отображаются в теле `403`-ответа непосредственно при запросе
распознавания, а не здесь.

**Ответы:**

| Код   | Описание                |
|-------|-------------------------|
| `200` | Текущий снимок лицензии |

**Пример ответа (200):**

```json
{
  "mode": "online",
  "status": "valid",
  "used": 1204,
  "limit": 50000,
  "windowResetsAt": "2026-10-15T00:00:00Z",
  "expiresAt": "2027-09-01T00:00:00Z",
  "product": "OCR",
  "tariff": "BUSINESS"
}
```

| Поле             | Тип     | Описание                                                                                                            |
|------------------|---------|---------------------------------------------------------------------------------------------------------------------|
| `mode`           | string  | `trial`, `online`, `offline`, `none` (не инициализировано / неизвестно / token-stub)                                |
| `status`         | string  | `valid`, `expired`, `none` (остальные причины отказа сворачиваются в `none` и отображаются только в теле `403`)     |
| `used`           | integer | Число запросов, засчитанных в активный счётчик за текущее 30-дневное окно                                           |
| `limit`          | integer | Лимит запросов на 30-дневное окно. `-1` — без квоты, `0` — лицензии нет вовсе, положительное значение — бюджет окна |
| `windowResetsAt` | string  | RFC 3339 UTC момент сброса 30-дневного счётчика. Пусто, если `limit` равен `0` или `-1`                             |
| `expiresAt`      | string  | RFC 3339 UTC момент истечения самой лицензии. Пусто, если `.lic` не загружен                                        |
| `product`        | string  | Продуктовая линейка, к которой привязан `.lic` (например, `OCR`). Пусто, если `.lic` нет                            |
| `tariff`         | string  | Тарифный план из `.lic` (например, `BUSINESS`). Пусто, если `.lic` нет                                              |

### Активация лицензии

```
POST /license/activate
```

Отправляет код активации на License Server, сохраняет полученный подписанный `.lic`-файл и переинициализирует подсистему
лицензирования — перезапуск не требуется. Идемпотентен для одной и той же пары «машина + код»: сервер вернёт
закэшированный `.lic`, не расходуя новый слот.

Эндпоинт исключён из проверки лицензии, поэтому заблокированный (без лицензии / с истёкшей лицензией) сервер всё равно
можно активировать. Он ограничен admin allowlist (`reload_allow`) — вызовы не из списка получают `403`. Обмен с License
Server может занимать до 15 секунд, и одновременно выполняется только одна активация — повторный вызов во время
выполнения получит `409`.

**Тело запроса:**

```json
{
  "activationCode": "XXXX-XXXX-XXXX-XXXX"
}
```

**Ответы:**

| Код   | Описание                                                                                                                         |
|-------|----------------------------------------------------------------------------------------------------------------------------------|
| `200` | Активировано — снимок лицензии с `activated: true`                                                                               |
| `400` | Поле `activationCode` отсутствует или пусто                                                                                      |
| `403` | IP вызывающего не входит в список `reload_allow`                                                                                 |
| `409` | Другая активация уже выполняется на этом сервере — повторите запрос позже                                                        |
| `501` | Подсистема лицензирования отключена на этапе компиляции (сборка `PROVISION_NO_LICENSE`)                                          |
| `502` | Активация не удалась — неверный/отозванный код, нет свободного слота, либо License Server недоступен; причина указана в `detail` |

**Пример ответа (200):**

```json
{
  "mode": "online",
  "status": "valid",
  "used": 0,
  "limit": 50000,
  "windowResetsAt": "2026-10-22T00:00:00Z",
  "expiresAt": "2027-09-01T00:00:00Z",
  "product": "OCR",
  "tariff": "BUSINESS",
  "activated": true,
  "detail": "activated in online mode"
}
```

### Распознавание документа (processing)

```
POST /processing/{template}
```

Основной эндпоинт распознавания. Принимает изображение или PDF в бинарном виде либо через multipart/form-data (поле
`file`/`body`).

**Параметры пути:**

| Параметр   | Тип    | Описание                                                         |
|------------|--------|------------------------------------------------------------------|
| `template` | string | Шаблон документа (см. [Шаблоны документов](#шаблоны-документов)) |

**Параметры запроса:** см. [Параметры запроса](#параметры-запроса).

**Тело запроса:** изображение или PDF в бинарном виде, либо multipart с полем `body` / `file`.

**Ответы:**

| Код   | Описание                                                                                                                                    |
|-------|---------------------------------------------------------------------------------------------------------------------------------------------|
| `200` | Результат распознавания                                                                                                                     |
| `400` | Некорректный запрос: отсутствует поле file, неизвестный шаблон, некорректные `language`/`pagesFrom`/`pagesTo`, нечитаемый/зашифрованный PDF |
| `415` | Не удалось декодировать изображение                                                                                                         |
| `500` | Внутренняя ошибка при обработке (модель не загружена, ошибка CUDA, конфиг шаблона не парсится)                                              |
| `503` | Очередь GPU-инференса перегружена — повторите запрос согласно заголовку `Retry-After`                                                       |

## Параметры запроса

`/processing/{template}` и `/processing2/{template}` принимают одинаковый набор параметров запроса:

| Параметр    | Тип             | По умолчанию       | Описание                                                                                                                                                                                                                                                       |
|-------------|-----------------|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `language`  | array of string | `[rus,eng]`        | Выбор распознавателя, через запятую (параметр также может повторяться). См. таблицу ниже. Неизвестные значения → `400`.                                                                                                                                        |
| `pagesFrom` | integer         | `0`                | **Только для PDF.** Первая обрабатываемая страница, нумерация с 0, включительно. Для изображений игнорируется.                                                                                                                                                 |
| `pagesTo`   | integer         | последняя страница | **Только для PDF.** Конец диапазона страниц, **исключая** указанную (`pagesFrom=0&pagesTo=3` = первые три страницы). Должен быть `>= pagesFrom`, иначе `400`. Диапазон за пределами документа — не ошибка: ответ `200` с пустым `pages` и реальным `maxPages`. |

**Значения `language`:**

| Значение                     | Поведение                                                                                                                                                                                                           |
|------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| *(не указано)* или `rus,eng` | Печатный текст, все символы обоих алфавитов (кириллица и латиница) через автоматический маршрутизатор скриптов, без фильтрации.                                                                                     |
| `rus`                        | Всё читается русским распознавателем.                                                                                                                                                                               |
| `eng`                        | Всё читается латинским распознавателем; вывод ограничен цифрами, пунктуацией, символами и буквами ASCII. Буква вне этого набора не транслитерируется, а заменяется наиболее вероятной допустимой (`café` → `cafe`). |
| `literal_rus`                | **Рукописный** русский текст (детекция слов на основе масок + рукописная CRNN; извлечение таблиц отключено). Любая комбинация, включающая `literal_rus`, также запускает путь распознавания рукописного русского.   |

## Обработка PDF

PDF-документы разбиваются на страницы и обрабатываются постранично; результат по всем страницам объединяется в единый
массив `pages` объекта `Document`, так же как для многостраничного изображения.

Необязательные параметры запроса `pagesFrom` / `pagesTo` ограничивают обработку окном страниц. При отправке PDF объект
`Document` в ответе содержит три дополнительных поля (отсутствуют для изображений):

| Поле        | Описание                                                                                                                                       |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `pagesFrom` | Запрошенное начало диапазона (нумерация с 0, включительно), эхо параметра запроса; `0`, если параметр не был указан.                           |
| `pagesTo`   | Запрошенный конец диапазона (не включая указанную страницу), эхо параметра запроса; при отсутствии параметра — общее число страниц документа.  |
| `maxPages`  | Реальное общее число страниц документа независимо от запрошенного диапазона — позволяет клиенту пагинировать без дополнительного проб-запроса. |

Значения `page_number` внутри `pages` всегда соответствуют **исходным** позициям в документе (нумерация с 1), а не
пересчитываются относительно запрошенного окна.

Если обработка не удалась для всех страниц запрошенного диапазона, эндпоинт вернёт `500` с сообщением, начинающимся с
`page N:`. Если не удались только некоторые страницы, ответ всё равно будет `200`, такие страницы просто отсутствуют в
`pages` (это можно обнаружить по разрывам в `page_number` относительно `pagesFrom`/`pagesTo`), а в лог сервера пишется
по одной строке ошибки на каждую неудавшуюся страницу.

## Формат ответа

### Структура верхнего уровня

```json
{
  "documents": [
    {
      "width": 715,
      "height": 999,
      "schema_version": 1,
      "pages": []
    }
  ]
}
```

| Поле             | Тип    | Описание                                                                                       |
|------------------|--------|------------------------------------------------------------------------------------------------|
| `width`          | int    | Ширина исходного файла в пикселях (или пунктах PDF)                                            |
| `height`         | int    | Высота исходного файла в пикселях (или пунктах PDF)                                            |
| `schema_version` | number | Версия формата ответа                                                                          |
| `pages`          | array  | Страницы документа (обычно 1–2 для изображений; до числа страниц для PDF)                      |
| `pagesFrom`      | int    | **Только для PDF.** Запрошенное начало диапазона страниц (см. [Обработка PDF](#обработка-pdf)) |
| `pagesTo`        | int    | **Только для PDF.** Запрошенный конец диапазона страниц                                        |
| `maxPages`       | int    | **Только для PDF.** Реальное общее число страниц документа                                     |

---

### Объект `Page`

```json
{
  "page_number": 1,
  "rotation": 0,
  "loc": {
    "x1": 0,
    "y1": 0,
    "x2": 715,
    "y2": 999
  },
  "blocks": [],
  "paragraphs": [],
  "tables": [],
  "figures": []
}
```

| Поле          | Тип    | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|---------------|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `page_number` | int    | Номер страницы (начиная с 1, исходная позиция в документе)                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `rotation`    | number | Угол поворота по часовой стрелке (в градусах), на который нужно повернуть страницу «как есть», чтобы текст читался прямо. `0` — уже прямая, `90`/`180`/`-90` — повороты на четверть. Для OCR-страниц значение также включает остаточную коррекцию наклона (например, `-7.43`), если включён `page_deskew`. Отсутствует, если сеть определения ориентации отключена, её веса не найдены, шаблон явно отказывается от неё, либо сеть не была достаточно уверена — отсутствие поля **не равнозначно** значению `0`. |
| `loc`         | object | Bounding box страницы в пикселях                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `blocks`      | array  | Плоский список всех распознанных блоков на странице                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `paragraphs`  | array  | Сгруппированные блоки; присутствует только для шаблонов `passport`/`snils`                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `tables`      | array  | Распознанные таблицы (пусто для шаблонов `passport`/`snils`)                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `figures`     | array  | Зарезервировано на будущее; на текущий момент всегда `[]`                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

### Объект `Block`

Встречается в `page.blocks`, `paragraph.blocks` и `table.cells[r][c].blocks`.

```json
{
  "text": "ИВАНОВ",
  "tag": "lastName",
  "prob": 1.0,
  "det_prob": 1.0,
  "loc": {
    "x1": 328,
    "y1": 515,
    "x2": 422,
    "y2": 528
  }
}
```

| Поле       | Тип    | Описание                                                                                                                                                                                                                                                                                                                           |
|------------|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `text`     | string | Распознанный текст блока                                                                                                                                                                                                                                                                                                           |
| `tag`      | string | Семантический тег (например, `lastName`, `dateIssued`, `word`, `header`, `data`)                                                                                                                                                                                                                                                   |
| `prob`     | float  | Уверенность распознавания: нормированная по числу символов прямая CTC-вероятность `text` для данного кропа (0–1)                                                                                                                                                                                                                   |
| `det_prob` | float  | Уверенность в обнаружении самой рамки. Не зависит от `prob`: высокое значение `prob` при низком `det_prob` указывает на область, которая была уверенно распознана, но вызывает сомнения. Поле отсутствует, если рамка получена не с помощью детектора CRAFT (например, области, выделенные на основе масок, или рукописный текст). |
| `loc`      | object | Bounding box блока: `x1`, `y1`, `x2`, `y2`                                                                                                                                                                                                                                                                                         |

### Объект `Table`

Присутствует при обработке шаблонов `default`, `agreement` и `regulation`. `cells` — двумерный массив по строкам:
внешний массив — строки, внутренний — ячейки строки.

```json
{
  "table_number": 1,
  "cells": [
    [
      {
        "tag": "header",
        "text": "Код",
        "prob": 1.0,
        "colspan": 1,
        "rowspan": 1,
        "loc": {
          "x1": 358,
          "y1": 334,
          "x2": 402,
          "y2": 386
        },
        "blocks": [
          {
            "text": "Код",
            "tag": "header",
            "prob": 1.0,
            "det_prob": 1.0,
            "loc": {
              "x1": 358,
              "y1": 334,
              "x2": 402,
              "y2": 386
            }
          }
        ]
      }
    ],
    [
      {
        "tag": "data",
        "text": "796",
        "prob": 1.0,
        "det_prob": 1.0,
        "colspan": 1,
        "rowspan": 1,
        "loc": {
          "x1": 358,
          "y1": 386,
          "x2": 402,
          "y2": 455
        },
        "blocks": [
          {
            "text": "796",
            "tag": "data",
            "prob": 1.0,
            "loc": {
              "x1": 358,
              "y1": 386,
              "x2": 402,
              "y2": 455
            }
          }
        ]
      }
    ]
  ]
}
```

| Поле ячейки | Тип    | Описание                              |
|-------------|--------|---------------------------------------|
| `tag`       | string | `header` — заголовок, `data` — данные |
| `text`      | string | Текст ячейки                          |
| `prob`      | float  | Уверенность (0–1)                     |
| `colspan`   | int    | Объединение столбцов                  |
| `rowspan`   | int    | Объединение строк                     |
| `loc`       | object | Bounding box ячейки                   |
| `blocks`    | array  | Отдельные блоки внутри ячейки         |

`table_number` (нумерация с 1) идентифицирует таблицу на странице.

## Примеры кода

### Python — передача изображения в бинарном виде

```python
import requests

with open("passport.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8098/processing/passport",
        data=f,
        headers={"Content-Type": "image/jpeg"},
    )

result = response.json()
doc = result["documents"][0]
page = doc["pages"][0]

# Извлечь все поля по тегу из параграфов
fields = {p["tag"]: p["text"] for p in page["paragraphs"]}
print(fields)
# {'birthPlace': 'ГОР.', 'codeIssued': '741-002', 'dateIssued': '16.03.2007', ...}
```

### Python — передача через multipart/form-data

```python
import requests

with open("snils.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8098/processing/snils",
        files={"file": ("snils.jpg", f, "image/jpeg")},
    )

result = response.json()
page = result["documents"][0]["pages"][0]
fields = {p["tag"]: p["text"] for p in page["paragraphs"]}
print(fields)
```

### Python — обход таблиц (шаблон default)

```python
import requests

with open("balance.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8098/processing/default",
        data=f,
        headers={"Content-Type": "image/jpeg"},
    )

page = response.json()["documents"][0]["pages"][0]
for table in page["tables"]:
    for row in table["cells"]:
        print([cell["text"] for cell in row])
```

### Python — получить все блоки со страницы

```python
import requests

with open("document.png", "rb") as f:
    response = requests.post(
        "http://localhost:8098/processing/default",
        data=f,
        headers={"Content-Type": "image/png"},
    )

page = response.json()["documents"][0]["pages"][0]
for block in page["blocks"]:
    print(block["text"], block["tag"], block["prob"], block["loc"])
```
